## Descripción

En esta práctica revisamos conceptos relacionados con la
**Capa Física del modelo OSI**, particularmente la representación de bits
mediante señales y el fenómeno conocido como **Bit-Flip**.


---

## Objetivos

- Experimentar con conceptos relacionados con la Capa 1 del modelo OSI.
- Representar información como una secuencia de bits.
- Representar los bits mediante señales simuladas de voltaje.
- Emular la alteración de un bit durante una transmisión.
